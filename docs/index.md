# HEIMDALL Flux Card — Documentation

Welcome to the documentation for **HEIMDALL Flux Card**, an animated power-flow
card for Home Assistant adapted for dual-battery energy systems.

> This is a personal fork of [Power Flux Card](https://github.com/jayjojayson/power-flux-card)
> by [@jayjojayson](https://github.com/jayjojayson) (MIT). For a universal,
> single-battery card, please use and support the original.

These docs follow the [Diátaxis](https://diataxis.fr/) structure — four kinds
of documentation for four different needs:

| If you want to… | Read |
| --- | --- |
| **Learn** by setting the card up step by step | [Getting started](getting-started.md) (tutorial) |
| **Install** or update the card | [Installation](installation.md) (how-to) |
| **Look up** a configuration option | [Configuration reference](configuration.md) |
| **Understand** what each element means | [Features explained](features.md) |
| **Fix** a problem | [Troubleshooting](troubleshooting.md) |
| **Build** or modify the card | [Development](development.md) |
